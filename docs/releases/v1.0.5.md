# CodexLauncher v1.0.5

## Changes

- Add Codex reset-credit details and preserve card counts when quota windows are absent.
- Improve Bridge pairing, explicit device replacement, adapter guidance and background monitoring.
- Keep device-list selection and reading position during refresh.
- Reduce page relayout work during window resizing and keep content within the viewport.
- Update quota timestamps and account presentation.

## Download

This release provides the self-contained Windows x64 portable ZIP and its SHA-256
checksum. Extract it into a writable folder and run `CodexLauncher.exe`.

## Compatibility note

For the most accurate Bridge cache and source-time display, use this desktop release
with the matching updated Android app when that APK is released. Older Android builds
may show a cached quota response as current after an upstream refresh failure. The
Android parser also rejects raw usage percentages outside 0–100; the desktop API
intentionally retains those source values and clamps only the remaining percentage.
