# 阶段四实施细化

沿用已批准计划与补充规格，按当前授权执行；不增加产品范围。

1. 网络来源按用户选择的 adapterId 精确解析物理 Private IPv4；保留当前地址，地址失效后仅选择同一网卡的新地址。不能验证时暂停。
2. 串行协调器拥有监听和发现生命周期；网络事件立即失效请求闸门，随后停旧服务再建新服务。休眠暂停，恢复重新解析。定期检查弥补网络类别变化不发地址事件的情况。
3. 每次重绑沿用原身份/设备仓库，建立新配对服务与正确端点，作废旧邀请和未完成交付。发现仅在邀请/待批准或已有设备时需要。
4. DNS-SD 显式服务地址与最小元数据；固定依赖存在非网卡绑定的传统单播回复路径，未取得指定接口完整出站证据前默认阻塞发现。失败不停止 HTTPS，绝不回退全网卡。
5. 提供直连说明及只针对当前可执行程序、Private、LocalSubnet、指定 TCP 端口/UDP5353 的固定前缀防火墙命令；仅生成文本，用户自行运行。
6. 合成生命周期与真实回环 HTTPS 重绑测试、全量回归、独立只读审查、阶段报告和索引。真实网卡、休眠和隔离包捕获另列未验证事项。

Ruling：不把API接口筛选兼容性当作隔离证明。成本：当前生产默认发现状态为 MDNS_ISOLATION_UNVERIFIED，二维码/手动HTTPS直连保留。
